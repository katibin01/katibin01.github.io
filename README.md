# Birthday Greeting Web App

A simple and interactive birthday greeting web application with animations and personalized messages.

## Features

- Interactive welcome page with name input
- Personalized birthday message
- Current date display in Indonesian format
- Animated elements
- Responsive design

## Project Structure

```
gabut/
├── index.html
├── happybird.html
├── style.css
├── main.js
└── README.md
```

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage

## How to Use

1. Open `happybird.html` in a web browser
2. Enter the recipient's name in the input field
3. Click "Submit" button
4. View the personalized birthday greeting with current date

## Code Features

- Input validation
- Date localization (Indonesian format)
- Dynamic content display
- CSS animations
- Responsive design elements

## Customization

You can customize the following elements:
- Color scheme in `style.css`
- Message text in `happybird.html`
- Date format in `main.js`

## Development

To modify this project:
